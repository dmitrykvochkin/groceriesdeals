## Caption

Not sure what to ask? Start with one of these prompts.

Add the following details to get a more useful result:

- Your budget
- Number of people
- Dietary preferences
- Number of days you want to plan
- Ingredients you already have

Which useful prompt is missing? Leave it in the comments—perhaps we will
include it in the next post.

kortingzoeker.com currently supports Picnic only. Prices and availability can
change, so always verify your final basket.

## Visual direction

- Give each prompt its own uncluttered slide.
- Make the prompt easy to screenshot or copy.
- Number prompts from one to five.
- Use a consistent visual template so the carousel feels like a reference
  guide.
- Emphasize "Save this post" rather than asking only for likes.
